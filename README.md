# TRPG 跑團介面產生器

給 TRPG（CoC 等）實況用的 OBS 畫面外框產生器。左邊編輯、右邊即時預覽 1920×1080。

👉 https://knightleft.github.io/trpg-overlay/

## 使用方式

1. 打開上面的網址，在左邊編輯標題、劇情筆記、配色、角色等內容（自動存在瀏覽器裡）。
2. 把畫面放進 OBS（瀏覽器來源，寬 1920、高 1080）：
   - **沒有上傳圖片**：按「複製 OBS 網址」，貼到 OBS 瀏覽器來源的網址欄。
   - **有上傳圖片（含 GIF）**：網址會太長，改按「儲存 OBS 檔案」，OBS 瀏覽器來源勾「本機檔案」選這個檔。
3. OBS 讀不到瀏覽器裡的存檔，**每次修改後都要重新複製網址，或重新儲存 OBS 檔案**（OBS 來源按右鍵「重新整理」）。

## 畫面上的區塊

- **劇情畫面**：16:9 挖空透明，把圖片或遊戲畫面放在這個來源的下面就會透出來。右上角可放 1～5 行「前段＋後段」資訊（例：地點　S市）。
- **角色狀態**：每個角色一個空格，給 OBS 疊上 CCFOLIA 的瀏覽器來源。名字下面可加副標題（職業、HO、玩家名）。每個角色的 CSS、網址、OBS 位置與大小都在編輯器的角色區。
- **玩家卡**：每個角色格左邊可放一張玩家卡，直書的玩家名字＋[Reactive](https://reactive.fugi.tech/)（Discord 語音反應頭像）單人連結，可調上下左右。主持人的 Reactive 放在圓形頭像框裡。都嵌在介面裡，OBS 不用另外加來源。左欄寬度可調，加寬時劇情畫面等比例縮小。
- **場內（劇情扮演）／場外（玩家閒聊）／聊天室／劇情筆記**：標題都可自訂；場外、劇情筆記可關閉。前三個只有標題，內容由 OBS 疊上去。
- **主持人**（預設隱藏）、**VTuber 區**（高度可調，框內下緣可疊跑馬燈空格）、**標題列**（右側留時間空位）。

## OBS 來源順序（由下到上）

劇情畫面的圖片／影片 → 跑團介面 → 各角色的 CCFOLIA
